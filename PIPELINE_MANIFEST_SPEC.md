## THE CORE INSIGHT (from ChatGPT, validated by all)

We don't have a render problem. We have an ORCHESTRATION problem.

Every bug — duplicate outro, wrong PiP timing, social card desync, abrupt cuts,
missing music — comes from the same root cause: the assembler makes GUESSES about
what should happen based on heuristics (position in dialogue list, special-case
routing, "first host line maybe cold open"). That's why fixes in one area break
another.

**THE FIX: A canonical episode manifest generated BEFORE rendering begins.**

The manifest is a structured JSON timeline that specifies EXACTLY what happens at
every moment of the episode. The renderer becomes dumb — it just executes the
manifest. No inference. No guessing. No heuristics.

## SECTION 2: THE AUDIO MASTERY CHAIN (from Gemini + ChatGPT + Perplexity)

### Per-Clip Processing (before assembly):
```
1. Highpass 50Hz + Lowpass 15kHz (remove rumble + hiss)
2. Multi-band compand (studio consistency across diverse YouTube mics)
3. Loudnorm I=-16:TP=-1.5:LRA=7 (broadcast standard)
```
FFmpeg: `-af "highpass=f=50,lowpass=f=15000,loudnorm=I=-16:TP=-1.5:LRA=7"`

### Per-Narration Processing:
```
1. Compressor ratio 2:1, soft knee (tame ElevenLabs peaks)
2. Loudnorm I=-16 (match clips)
```

### Music Ducking (Gemini's key insight — sidechain compression):
```
Instead of static "-14dB under voice":
- Music plays at -10dB when no voice
- When voice detected, music ducks to -22dB automatically
- FFmpeg sidechaincompress: voice PUSHES music down in real-time
```
```bash
ffmpeg -i narration.wav -i music.mp3 -filter_complex \
  "[1:a]asplit[music][sc];[0:a][sc]sidechaincompress=threshold=0.02:ratio=6:attack=10:release=300[duck];[duck]amix=inputs=1:duration=first[out]" \
  -map "[out]" ducked_output.wav
```

### Final Master Bus (on complete episode):
```
1. Two-pass loudnorm (guarantees consistent program loudness)
2. Limiter at -1.5 dBTP (no clipping on any platform)
3. Loudness range check (LRA 7-11 for dynamic but controlled)
```

## SECTION 3: VISUAL UPGRADES (from Gemini + Grok)

### Virtual Zoom/Pan (stops "PowerPoint with audio" feel):
During narrator segments, apply slow 1.1x zoom over 30 seconds:
```bash
ffmpeg -i bg.mp4 -vf "zoompan=z='min(zoom+0.001,1.1)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=900:s=1920x1080:fps=30"
```
This creates subconscious "approaching importance" — brain stays engaged.

### Word-Level Subtitle Highlighting (Gemini's #1 retention lever):
Since Whisper provides word-level timestamps, highlight the CURRENT word in red
while the rest of the sentence stays white. This is the "Hormozi style" that
increased short-form retention by 40% industry-wide in 2025.

Implementation: Generate ASS subtitle file from Whisper word timestamps.
Each word gets its own timing. Current word: `{\c&H0000CC&}` (red).
Previous/upcoming words: `{\c&HFFFFFF&}` (white).

### Background Glow Effect (makes 862KB cyberpunk file look intentional):
```bash
-filter_complex "[v]split[main][glow];[glow]boxblur=10:5,curves=all='0/0 0.5/0.2 1/1'[g];[main][g]blend=all_mode='screen'"
```

### Impact-Based Transitions (from Gemini):
- Clip score 80+: aggressive glitch transition (1.5s)
- Clip score 60-79: standard whoosh (1.0s)
- Clip score <60: gentle crossfade (0.5s)
The ENERGY of the edit matches the ENERGY of the content.

## SECTION 4: QC PIPELINE (from ChatGPT + Perplexity — THE MISSING PIECE)

### Asset Preflight (before render starts):
```python
def preflight_check(manifest):
    """Verify ALL assets exist and are valid BEFORE rendering."""
    errors = []
    for seg in manifest['segments']:
        # Audio exists and has duration
        if seg.get('audio') and not os.path.exists(seg['audio']):
            errors.append(f"MISSING AUDIO: {seg['audio']} for segment {seg['id']}")
        # Visual asset exists
        if seg.get('visual') == 'cyberpunk_bg' and not os.path.exists(CYBERPUNK_BG):
            errors.append("MISSING: cyberpunk_loop.mp4")
        # Clip exists and meets quality threshold
        if seg['type'] == 'clip':
            clip_path = seg['audio']
            if os.path.exists(clip_path):
                bitrate = get_bitrate(clip_path)
                if bitrate < 1_500_000:
                    errors.append(f"LOW QUALITY: {clip_path} at {bitrate/1e6:.1f}Mbps")
        # Screenshot exists (or fallback approved)
        if seg['type'] == 'social_card':
            ss = seg.get('card_data', {}).get('screenshot_path', '')
            if ss and not os.path.exists(ss):
                errors.append(f"MISSING SCREENSHOT: {ss} — will use text fallback")
    return errors
```

### Post-Render QC (blocks publish if fails):
```python
def post_render_qc(video_path, manifest):
    """Run automated quality checks BEFORE publishing."""
    results = {}
    
    # 1. Duration check
    duration = ffprobe_duration(video_path)
    expected = manifest['qc_expectations']['total_duration_range']
    results['duration'] = expected[0] <= duration <= expected[1]
    
    # 2. Loudness check (two-pass measurement)
    lufs = measure_loudness(video_path)  # ffmpeg loudnorm print_format
    results['loudness'] = abs(lufs - manifest['qc_expectations']['loudness_lufs']) < 2
    
    # 3. Silent gap detection
    silences = detect_silences(video_path, min_duration=2.0)
    results['no_dead_air'] = len(silences) == 0
    
    # 4. Black frame detection
    black_frames = detect_black_frames(video_path, min_duration=0.5)
    results['no_black_frames'] = len(black_frames) == 0
    
    # 5. Duplicate audio detection (catches outro repeat bug)
    results['no_audio_duplication'] = check_audio_uniqueness(video_path)
    
    # 6. True peak check
    true_peak = measure_true_peak(video_path)
    results['true_peak_ok'] = true_peak <= manifest['qc_expectations']['true_peak_dbtp']
    
    # PASS/FAIL
    passed = all(results.values())
    if not passed:
        send_telegram_alert(f"QC FAILED: {results}")
    return passed, results
```

## SECTION 5: EDITORIAL INTELLIGENCE (from Perplexity + ChatGPT)

### Rundown Planner:
Before clip selection, apply editorial rules:
- Never 3 macro topics in a row (mining, mining, mining = boring)
- Always start with highest-impact accessible clip
- At least 1 optimistic + 1 defensive segment per show
- Diversity: different speakers, different camera setups, different energy levels

### Inter-Segment Bridges:
Auto-generate 1-sentence bridges between segments via LLM:
"From mining difficulty to the macro picture..." 
"But it's not all bearish — here's the counterpoint..."
This makes the show feel like a continuous NARRATIVE, not a playlist.

### Script-to-Screen Shot Planning (ChatGPT's "biggest leap" suggestion):
Script writer outputs not just dialogue but VISUAL INTENT:
```json
{
  "line": "Saylor's tweet is the most liked of the day",
  "visual_mode": "social_card",
  "card_index": 0,
  "pip_active": false,

  "energy": "confident"
}
```
This closes the gap between what the narrator SAYS and what the viewer SEES.

## SECTION 6: CLIP PROTECTIVE MEASURES

### Fade-In/Fade-Out on EVERY Clip:
```bash
# 0.3s fade in, 0.5s fade out on audio
-af "afade=t=in:d=0.3,afade=t=out:st={duration-0.5}:d=0.5"
# 0.3s video fade in, 0.5s video fade out
-vf "fade=t=in:d=0.3,fade=t=out:st={duration-0.5}:d=0.5"
```
This is the INSURANCE POLICY. Even if sentence boundary detection fails,
the fade prevents jarring cuts.

### End-of-Clip Logic (belt + suspenders):
1. Sentence boundary detection (existing, improve accuracy)
2. Silence detection (existing, extend search window to 15s)
3. Forced fade-out if neither finds a clean end (NEW — always applied)
4. Never cut mid-word (check Whisper word timestamps)

## SECTION 7: DEGRADED MODE (from ChatGPT — operational resilience)

When things fail, degrade GRACEFULLY, don't crash:
- <5 qualifying clips: produce tight 3-clip show (don't force bad content)
- Tweet screenshots fail: use approved text card (already built)
- Background asset missing: use solid #0A0A0A with subtle vignette
- TTS fails on one line: regenerate with backup voice or skip line
- Social segment weak: omit entirely rather than ship broken cards
- Music not found: proceed without (don't block the render)

Every failure path produces ACCEPTABLE output, never broken output.

