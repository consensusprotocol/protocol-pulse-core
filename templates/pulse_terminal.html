FAQ
Common Questions
How is the API key delivered?
After successful payment, your API key is emailed immediately to the address you provide at checkout. The key starts with pp_cmd_. Store it securely — it won't be shown again in the dashboard.
When does my rate limit reset?
All rate limits reset at 00:00 UTC daily. The rate_limit.resets_at field in every API response shows the exact timestamp. Commander tier gets 1,000 requests per day.
What is the data source for topics and sentiment?
Topics and sentiment are derived from Protocol Pulse's own article database — published, human-reviewed Bitcoin intelligence articles. Sentiment uses both structured signals from the SentimentBuffer and a keyword-frequency fallback for real-time coverage.
Can I cancel anytime?
Yes. Cancel via the Stripe billing portal link included in your confirmation email. Your key remains active until the end of the billing period.
Is this the same as the live terminal at /live?
No. The live terminal at /live is a visual dashboard for browsing. Pulse Terminal API is for programmatic access — designed for developers, algo traders, and data teams who want Bitcoin intelligence in their own products.
