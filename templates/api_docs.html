Protocol Pulse API

Access real-time Bitcoin market intelligence, articles, on-chain analytics, and more. Build on top of the most comprehensive Bitcoin data platform.

REST API JSON Responses Free Tier Available v2.0
Base URL
https://protocolpulse.io/api

Authentication

Public endpoints (market data, articles, search, feeds) require no authentication. Admin endpoints require session authentication via the login flow.

curl
# Public endpoint — no auth needed curl https://protocolpulse.io/api/btc-price # Returns: { "price": 97432, "change_24h": 2.34, "volume_24h": 28500000000, "market_cap": 1920000000000 }

Rate Limits

API requests are rate-limited per IP address. Exceeding limits returns HTTP 429.

TierLimitWindow
Public200 requestsper day
Authenticated1,000 requestsper day
Premium10,000 requestsper day

Market Data

GET /api/btc-price Current BTC price

Returns the current Bitcoin price, 24h change, volume, and market cap. Updated every 30 seconds.

Response
{ "price": 97432, "change_24h": 2.34, "volume_24h": 28500000000, "market_cap": 1920000000000, "last_updated": "2026-02-25T22:30:00Z" }

GET /api/market-dashboard Full market intelligence

Complete market intelligence payload including BTC price, Fear & Greed Index, mempool stats, on-chain metrics, and trending coins.

GET /api/market-dashboard/history Price history for charts

BTC price history for charting. Returns array of [timestamp_ms, price] pairs.

Parameters: days (int, 1-365, default 30)

Articles

Returns the latest published articles with title, summary, category, image, and publication date.

Search articles with AI-enhanced ranking. Handles Bitcoin terminology and provides highlighted snippets.

Parameters: limit (int, default 6)

Returns currently trending topics across all articles, scored by recency and engagement.

Code Examples

Python

Python
import requests # Get current BTC price resp = requests.get("https://protocolpulse.io/api/btc-price") data = resp.json() print(f"BTC: ${data['price']:,.0f} ({data['change_24h']:+.1f}%)") # Search articles resp = requests.get("https://protocolpulse.io/api/search", params={"q": "bitcoin etf"}) for article in resp.json()["results"]: print(f" - {article['title']}") # Get full market dashboard dashboard = requests.get("https://protocolpulse.io/api/market-dashboard").json() print(f"Fear & Greed: {dashboard['fear_greed']['value']} ({dashboard['fear_greed']['label']})")

// Get current BTC price const resp = await fetch('https://protocolpulse.io/api/btc-price'); const { price, change_24h } = await resp.json(); console.log(`BTC: $${price.toLocaleString()} (${change_24h > 0 ? '+' : ''}${change_24h.toFixed(1)}%)`); // Real-time price updates (poll every 30s) setInterval(async () => { const data = await fetch('/api/btc-price').then(r => r.json()); document.getElementById('price').textContent = `$${data.price.toLocaleString()}`; }, 30000);
