API Endpoints

GET /api/v1/signals/live Real-time BTC signal score

Returns composite signal score (0-100) from on-chain, sentiment, social, macro, and whale data.

curl -s https://protocolpulse.io/api/v1/signals/live \
  -H "X-Commander-Key: YOUR_KEY" | jq .

Params: ?limit=10 (max 50)

GET /api/v1/spaces/live Active X Spaces

Bitcoin Twitter/X Spaces detection with transcription summaries and live sentiment.

curl -s https://protocolpulse.io/api/v1/spaces/live \
  -H "X-Commander-Key: YOUR_KEY" | jq .
GET /api/v1/tradfi/signals TradFi correlation

Traditional finance signals: DXY, yields, SPX, gold with BTC relevance scoring.

curl -s "https://protocolpulse.io/api/v1/tradfi/signals?btc_only=true" \
  -H "X-Commander-Key: YOUR_KEY" | jq .

Params: ?limit=20 (max 50), ?btc_only=true

GET /api/v1/sentiment/composite Sentiment analysis

Multi-source sentiment: Fear & Greed, social velocity, narrative detection, market impact.

curl -s https://protocolpulse.io/api/v1/sentiment/composite \
  -H "X-Commander-Key: YOUR_KEY" | jq .
GET/POST /api/v1/alerts/webhook Alert webhook

GET: View current alerts. POST: Register a webhook URL for push alerts when signal velocity spikes.

curl -s -X POST https://protocolpulse.io/api/v1/alerts/webhook \
  -H "X-Commander-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"webhook_url":"https://your-server.com/hook","threshold_velocity":80}'
