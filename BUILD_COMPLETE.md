## What Was Built

### /mining Hub Page (mining_hub.html)
The definitive Bitcoin mining intelligence destination with 7 sections:

1. **Live Mining Command Center** — 8-card stat grid:
   - Network Hashrate (EH/s) — live via WebSocket + REST
   - Mining Difficulty (formatted T) + Epoch progress bar
   - Next Difficulty Adjustment (% predicted) + 3-epoch forecast chips
   - Hash Price ($/PH/day) — key miner profitability metric
   - Block Height + 3.125 BTC subsidy
   - Block Reward (USD equivalent, live BTC price)
   - Sats per TH/s per day
   - Mempool Fees (Low/Mid/High sat/vB)

2. **ASIC Profitability Calculator** — client-side, updates live:
   - Models: Antminer S21 Pro, S19 XP, Whatsminer M60S, Custom
   - Inputs: hardware cost, electricity cost slider ($0.02-$0.20), pool fee slider
   - Outputs: daily BTC, daily revenue, daily electricity, daily/monthly profit, break-even BTC price
   - Energy cost profitability zone bar (color gradient green→gold→red)
   - Hardware payback timeline bar (visual progress, months displayed)

3. **30-Day Hashrate Chart** — SVG polyline (no canvas):
   - Cyan hashrate line + fill gradient
   - White dim 7-day moving average
   - Gold dashed ATH line
   - Y-axis labels, X-axis date labels, hover tooltip
   - Animated pulse dot on current value

4. **Mining Pool Distribution** — SVG donut chart:
   - Top 10 pools last 7 days (mempool.space)
   - HHI (Herfindahl-Hirschman Index) displayed in chart center
   - Color-coded bar list with share percentages
   - Concentration warning: HIGH (red, >2500), MODERATE (gold, >1500), HEALTHY (green)
   - Centralization alert if top 3 > 51%

5. **Mining Intelligence Articles** — live from DB:
   - 4-column card grid (responsive to 1-col)
   - Auto-generated by mining_intel_monitor.py
   - "More Mining Intel →" link to /articles?category=mining

6. **Mining Intelligence Suite** — tool link cards:
   - Mining Risk, Solo Slayers, Dossier, Kill List

7. **Curated Mining CTA** — full-width glass panel:
   - Red top border, mailto:john@curatedmining.com CTA
   - "Built for serious capital allocators. Not retail."

### Backend Routes (core/routes.py)
- `GET /mining` → mining_hub.html
- `GET /api/mining/live-stats` → hashrate, difficulty, hash price, fees, 3-epoch forecast (cached 30s)
- `GET /api/mining/pools` → pool distribution + HHI (cached 5min)
- `GET /api/charts/hashrate-history` → 30-day trend + 7-day MA + ATH (cached 10min)
- `GET /api/mining/articles` → latest 8 mining articles from DB

### Mining Intel Monitor (services/mining_intel_monitor.py)
- RSS sources: Blockware Intelligence + Hashrate Index
- Deduplication: `mining_intel_seen` table (auto-created, migration-safe)
- Live data enrichment: fetches hashrate, BTC price, hash price, fees at article generation time
- Claude Sonnet-4-6 generates 800-1200 word original analysis (not copied from source)
- Saves to `articles` table with category='mining', source_type='mining_intel', published=True
- Max 3 articles/run (quota protection), 2s delay between API calls
- Cron: `0 */6 * * * source ~/protocol_pulse/.env && python3 -m services.mining_intel_monitor >> logs/mining_intel.log 2>&1`
