# Chart-to-Narration Mapping
When PBX discusses a topic, show the matching chart:
- price/BTC/bitcoin price -> price_chart.png
- hashrate/mining/hash rate -> hashrate_chart.png
- dominance/market share -> dominance_chart.png
- mempool/fees/transactions -> mempool chart
- fear and greed/sentiment -> fear_greed chart
Never show the wrong chart during narration.
