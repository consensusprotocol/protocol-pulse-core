 ---
 Key Design Decisions

 Layout: Split-screen

 - Avatar: left 40% (768px) — 512x512 avatar scaled + centered on dark bg
 - Data overlay: right 60% (1152px) — chart/card changes per segment
 - Bottom 4px red accent bar across full width

 Overlay types (per segment)

 - price_chart — 7-day BTC line chart with gradient fill, large price metric
 - mempool_viz — Fee tier bar chart + mempool gauge
 - hashrate_chart — Hashrate area chart + difficulty progress bar
 - article_card — Styled text card with PP branding
 - metric_card — Generic large-number display (fallback)

 Audio approach

 - Generate TTS per-segment (hook, seg_0, seg_1, seg_2, signoff)
 - Concatenate with 600ms silence gaps
 - Convert full narration to 16kHz mono WAV for avatar server
 - Individual segment durations drive overlay transition timing

 Avatar interaction

 - Send full narration WAV as base64 to POST localhost:8200/generate
 - Returns 512x512 mp4 (no audio) with lip-sync + blinks + head movement
 - Fallback if server down: loop static avatar image as video
