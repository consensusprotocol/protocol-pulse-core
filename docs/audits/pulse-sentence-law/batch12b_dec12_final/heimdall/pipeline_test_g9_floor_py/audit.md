## Consensus findings (majority of panel agrees)
- **[medium] pipeline/test_g9_floor.py:55** The spread assertion uses assertGreaterEqual, allowing the gate's re-encode spread to be any value from the measured spread up to 0.05. A larger spread lowers the luma floor, creating a fail-open: a tail whose luma falls between the spec-mandated floor (v2f_luma − measured_spread) and the gate's too-low floor (v2f_luma − larger_spread) would pass the gate but should fail per the spec ('G9 floor = v2f measured tail luma minus the MEASURED re-encode spread').
  - evidence: `self.assertGreaterEqual(Q.G9_REENCODE_SPREAD[fmt], spread[fmt]["spread"])`
  - fix: Replace with self.assertAlmostEqual(Q.G9_REENCODE_SPREAD[fmt], spread[fmt]["spread"], places=4) so the gate's spread must equal the measured spread (within floating-point tolerance), preventing the floor from being set lower than the spec requires.
