## Consensus findings (majority of panel agrees)
- **[medium] pipeline/word_diff.py:90** Q1/Q2: _edges_substituted_only only inspects opcodes whose expected-side span touches the first/last n words, but a 'replace' opcode can span beyond the edge window while its differing words sit inside it; conversely an insert/delete entirely inside the window is correctly rejected, but a replace whose expected span starts at index 0 yet extends past n passes even if the differing words are all beyond the edge. Also, the edge filter uses o[1] < n or o[2] > len(e) - n, so an opcode with i1 == i2 (pure insert) at exactly i1 == n is excluded, and a delete/insert at the edge returns False as documented — but a mid-word cut that difflib renders as a replace of unequal length also returns False, so a clipped/shifted cut cannot pass, matching ruling 159(b). For Q2: with expected ['the','the','cat'] and heard ['the','cat'], difflib yields delete of one 'the' at the edge — returns False (HARD), correct; but with expected ['a','b','a'] and heard ['a','b','b'], the trailing shift of the repeated 'a'->'b' is a one-for-one replace of non-material words, cleared if the audio matches even though the actual cut shifted — the audio check (span_fidelity over the interior) may still catch it if the prepared clip's interior differs, but if the shift is within the fades it will not, so the audio check does not always catch it. For Q3: the audio check covers the interior between fades; the edge words' own audio is G17c, separate; an edge substitution whose differing words lie inside the fades (partially) is cleared by the interior check while G17c measures the edge words' own audio — if G17c's window and the fades overlap differently, an edge failure could slip both, but this cannot be confirmed from the diff alone (G17c not shown).
  - evidence: `edge = [o for o in ops if o[1] < n or o[2] > len(e) - n]`
  - fix: Filter opcodes by whether their differing words actually lie within the edge windows (e.g. intersect [i1,i2) with [0,n) and [len(e)-n,len(e)) and require the differing words to be inside), and document the G17c/interior coverage gap or extend the audio check to the fades' audio.
