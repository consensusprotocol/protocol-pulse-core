## Raised but not agreed
- qwen27b:F1 [medium] Cache key omits model content/version. After an in-place Ollama model update (same tag 'gemma3:27b', new weights), all previously cached replies are stale but will be served because the key is only sha256(model_name, LLM_CTX, max_tokens, prompt). There is no model digest or timestamp in the key, so a re-run after a model pull silently uses pre-update outputs. (agree: 1)
- qwen27b:F2 [medium] Sentence-law defect: the JSON field is still named 'headline' but the prompt now instructs the model to emit 'ONE neutral sentence stating the CURRENT development itself'. A headline is conventionally a short fragment without terminal punctuation; a sentence requires a complete clause and a period. Downstream sentence-law validation (stand-alone sentence check) will reject headline-style fragments the model produces because the field name primes it toward headline form, while the instruction primes it toward sentence form. The two signals conflict and the model will inconsistently satisfy one or the other. (agree: 1)
- qwen27b:F3 [low] Concurrent-write race: two processes (or threads) that miss the cache for the same key both write to the identical tmp path (path + '.tmp'). The second process's open-for-write truncates the first's tmp file before the first's os.replace, so the first os.replace either picks up the second's bytes or raises FileNotFoundError (caught by except OSError: pass). At temperature 0 with fixed seeds the payloads should be identical, but if the backend is non-deterministic (e.g., Ollama with a non-seeded sampler), one process's validated result is silently discarded and the other's unvalidated-by-this-process result is stored. (agree: 1)
- qwen27b:F4 [low] The cache-read path assumes validate() raises on failure. If a caller passes a validator that returns a boolean (True/False) instead of raising, an invalid cached reply passes the 'if validate: validate(obj)' line (no exception), increments cache_hits, and is returned to the caller—bypassing the validation that the write-path would have enforced. This is a fail-open path for any validator written as a predicate rather than a guard. (agree: 0)
