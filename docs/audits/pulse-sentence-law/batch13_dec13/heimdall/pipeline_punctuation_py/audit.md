## Consensus findings (majority of panel agrees)
- **[medium] pipeline/punctuation.py:0** transfer_case never recases the first word of the transcript because the condition requires i > 0. The start of the transcript is a sentence boundary, so a sentence-initial capital present in the reference decode is not transferred to the verbatim first word. This can cause editorial_select.start_is_boundary to miss the capital evidence for the first word.
  - evidence: `if i and a[i] and r[:1].isupper() and v[:1].islower() and L.is_terminal(out[i - 1]["word"]):`
  - fix: Treat i == 0 as a sentence boundary, e.g. change the condition to: if a[i] and r[:1].isupper() and v[:1].islower() and (i == 0 or L.is_terminal(out[i - 1]["word"])):
  - raised by deepseek:F1; agree: deepseek, qwen27b
- **[medium] pipeline/punctuation.py:0** reference_decode passes the caller's settings dict directly as **kwargs alongside hard-coded language, word_timestamps, and initial_prompt. If the caller's verbatim decode settings contain any of those keys, transcribe() raises TypeError for duplicate keyword arguments. The docstring says settings are the caller's verbatim decode settings, which may include those keys.
  - evidence: `segs, _ = model.transcribe(source_path, language="en", word_timestamps=True, initial_prompt=PROMPT, **(settings or VERBATIM))`
  - fix: Merge settings with defaults and remove keys that are already passed explicitly, or only forward the allowed keys (e.g. beam_size, vad_filter) from settings.
  - raised by deepseek:F2; agree: deepseek, qwen27b

## Raised but not agreed
- qwen27b:F1 [low] `settings or VERBATIM` treats an empty dict as 'not provided', silently substituting the full VERBATIM defaults. A caller that passes a partial settings dict (e.g. only beam_size) loses vad_filter=False and the model falls back to its own default (often True), changing ASR segmentation and word alignment without any error. (agree: 1)

## Added in cross-examination (not voted on)
- deepseek: [medium] transfer_case strips leading/trailing whitespace from the word when recasing, so it changes more than the first letter and can break word boundary spacing in the reconstructed transcript.
- qwen27b: [low] transfer_case strips the word before recasing (`v = w["word"].strip()` then `w["word"] = v[0].upper() + v[1:]`), which silently removes any leading/trailing whitespace from the verbatim word. If the verbatim decode ever produces a word with surrounding spaces (e.g. a leading space from a word-boundary artefact), the stored word changes beyond just the first-letter case, violating the docstring's 'Only that first letter changes' guarantee and potentially breaking downstream word-key or timing alignment.
