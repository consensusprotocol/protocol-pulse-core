Severity: P0/P1 boundary; the truncation is real but the *decision* (formats) only reads `in_9x16`, so impact is evidence-only → **[P1]**.

**[P0-2] `formats_of` intersection logic is wrong for the medley case.** `package_pin.formats_of` returns `["16x9"]` if *any* segment's visual says `["16x9"]`, else `None`.
