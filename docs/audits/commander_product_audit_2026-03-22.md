## Cycle 1 — Individual Model Audits

### GEMINI 2.5 PRO

**1. KILLER FEATURE GAP: "Accumulation Zone" Advisor**
A proactive, personalized tool that translates the product's intelligence into the user's core objective — when to buy. User defines their strategy criteria (Pulse Score thresholds, drawdown %, MVRV Z-Score zones, ETF flow triggers). Dashboard shows `MONITORING` | `ZONE ACTIVE` status. When conditions are met, high-signal notification fires. Closes the loop between intelligence and action — turns Commander from a briefing into a personal acquisition strategist.

**2. WEAKEST FEATURE: Fear & Greed Meter**
Redundant with the Pulse Score. Already free everywhere (Alternative.me). Putting a generic meter next to a proprietary score cheapens the whole product. Replace with on-chain metrics the target audience actually respects: MVRV Z-Score, Realized Price, Puell Multiple.

**3. VIRAL MOMENT: "Sovereign Snapshot"**
Shareable image generated from Stack Tracker: anonymized stack size, current Pulse Score, dynamic historical context quote ("Last time signal was this low: BTC +1,200% in 18 months. Conviction is forged in fire."), Protocol Pulse watermark. Personal, visually striking, conviction-aligned — perfect for X.

**4. CYPHERPUNK CHECK: "Feels like fintech with a cypherpunk hat"**
Fixes needed: (1) Accept Bitcoin via Lightning Network as default payment — Stripe as "legacy finance" option. (2) Anonymous sign-up option — no mandatory email. (3) Node connection status indicator — green light + block height = "Don't trust, verify."

**5. $29 VALUE: Live Spaces Intercept Alerts**
Would pay for this alone. Real-time key quotes from Saylor/Pysh/Broyles conversations while you're in a meeting = having a personal intelligence analyst. That service costs thousands. At $29, it's a steal.

**6. TECHNICAL EDGE: Proprietary Mempool & Lightning Analysis**
Deep mempool composition analysis (consolidation patterns, multi-sig scripts, fee-priority whale transactions) = leading indicator before blocks confirm. Lightning Network capacity/channel growth tracking = unique signal of Bitcoin's transition from speculative to transactional.

**7. RETENTION MECHANIC: "Daily Sovereign Check-in"**
Daily "Confirm Your Stack" ritual that unlocks unique sovereignty insights: "Your stack could power 3.5 American homes for a year" / "Your stack is 1/12,000,000th of total supply" / "Energy to 51% attack your stack could power a small city."

**8. WILDCARD: "Commander's Canary" — Dead-Man's-Switch Inheritance**
Privacy-preserving dead-man's-switch. User defines check-in period, writes encrypted instructions for finding keys (not the keys themselves), designates recipient. Timer expires → message auto-sends. Moves Commander from market tool to essential piece of multi-generational wealth strategy. Near-absolute retention.

## Revised Feature Set

### V1 — Launch Features (build now)

1. **The Morning Brief** — 3-minute daily intelligence briefing
   - The Number (BTC price + 24h change)
   - What Happened (3-4 signal bullets, not headlines)
   - The Take (cypherpunk editorial — no hedging)
   - Watch List (3 specific data points to monitor today)
   - Replaces F&G Meter with on-chain metrics (MVRV Z-Score, Puell Multiple)

2. **Accumulation Zone Advisor** — operational co-pilot
   - User defines accumulation criteria (Pulse Score thresholds, drawdown %, on-chain signals)
   - Dashboard status: `MONITORING` | `ZONE ACTIVE`
   - Proactive high-signal alerts when conditions align
   - Historical context: "Last 5 times conditions matched: [dates + outcomes]"

3. **Pulse Score** — composite intelligence rating (0-100)
   - 5 sub-scores: on-chain, macro, sentiment, institutional flow, market structure
   - Updated every 4 hours
   - 7-day sparkline + historical context
   - **Prediction Accuracy Tracker**: "Predicted X% of major reversals since launch"

4. **Live Spaces Intercept Alerts** — real-time thought leader intelligence
   - Push notification when TIER1 speaker goes live
   - In-app transcript stream with key quote extraction every 5 minutes
   - Post-space recap within 30 minutes
   - The single most differentiated feature

5. **Sovereign Stack Tracker** — private, local-storage holdings view
   - Stack value in BTC, fiat, gold oz, oil barrels, S&P units
   - "If Bitcoin reaches $X" calculator
   - DCA projection (1/5/10 years)
   - **Sovereign Snapshot**: shareable image with stack + Pulse Score + conviction quote
   - All data stays in browser — never sent to server

6. **Intel Feed** — high-signal event stream
   - Scored 1-10, only 7+ shown
   - On-chain anomalies, whale movements, ETF flows, Fed/geopolitical events
   - Auto-refresh every 5 minutes, unread count badge

7. **Commander Briefing Archive** — searchable history
   - Every morning brief since launch, searchable by date/topic/price range
   - Each brief linked to subsequent 7-day price action
   - Pattern recognition learning tool

### V1.5 — Fast Follow (build within 30 days of launch)

8. **Lightning Network Payments** — cypherpunk authenticity signal
   - LN as primary payment, Stripe as "legacy finance" fallback
   - Anonymous sign-up option (username + password only, email optional)

9. **Commander's Canary** — dead-man's-switch inheritance
   - User-defined check-in period (e.g., 90 days)
   - Encrypted instructions for key recovery (not the keys themselves)
   - Auto-send to designated recipient if timer expires
   - Near-absolute retention mechanic

10. **Proprietary On-Chain Intelligence Layer**
    - Deep mempool composition analysis (consolidation patterns, multi-sig, fee-priority whales)
    - Whale wallet clustering and behavior tracking
    - Leading indicators before block confirmation

### V2 — Ambitious Expansion

11. **Bitcoin War Room Simulation** — scenario planner
    - "What if Fed raises 50bps" / "China lifts mining ban" projections
    - Historical data + on-chain metrics for forward-looking strategy
    - Must be carefully framed to avoid financial advice perception

12. **Cypherpunk Signal Feed** — community intelligence
    - Anonymous, vetted on-chain observations from community
    - Signal-strength scored, curated
