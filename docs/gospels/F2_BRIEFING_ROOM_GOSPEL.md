## WHAT THIS FEATURE IS

The Market Briefing Room is Protocol Pulse's scheduled video intelligence product.
HeyGen Sarah delivers 3 scripted briefings per day at market-critical times.
These are NOT live — they are generated programmatically, auto-scripted by Claude,
rendered by HeyGen, stored, and served from the rebuilt briefing page.

This is distinct from the Oracle page (on-demand AI conversation).
Briefing Room = scheduled, produced, archive-able.
Oracle = on-demand, conversational, ephemeral.

## THE LAWS

### LAW 1: HeyGen Sarah is the ONLY avatar for Briefing Room
- Avatar ID: d259c335741f4fc0b061e04c59388b4e
- Resolution: 1280x720 minimum
- Cost: $1/min — budget 2 minutes per briefing = $6/day = ~$180/month
- DO NOT use Wav2Lip for briefings — HeyGen quality is higher, cost is controlled

### LAW 2: Three briefings per day, fixed schedule
- 07:00 ET — Pre-market: overnight developments, Asian market close
- 09:30 ET — Market open: what to watch today
- 16:30 ET — Market close: what happened, what it means for Bitcoin
- Schedule is implemented as cron, NOT manual triggers
- If HeyGen API fails, log and skip — do NOT retry more than twice

### LAW 3: Always show last 3 briefings
- Below the live/latest briefing: always render the 3 previous briefings
- This is a PERMANENT rule — never show only the current briefing
- Each past briefing shows: title, timestamp, duration, thumbnail, play button

### LAW 4: /stage → 302 redirect → /briefing
- The current /stage route stays as a redirect permanently
- New canonical URL: /briefing
- Template: market_briefing.html (new file, replaces stage.html eventually)
- stage.html is NOT deleted — it remains as legacy

### LAW 5: Scripts are Claude-generated, not hardcoded
- Each briefing script is generated by Claude claude-sonnet-4-6 at generation time
- Script pulls from: latest articles, live BTC price, mempool stats, network data
- Max script length: 90 seconds spoken (approx 180 words at 120 WPM)
- Script must pass: no em dashes, no ellipses, no markdown, plain spoken English

### Briefing Generation Flow
```
Cron fires at 07:00/09:30/16:30 ET
  → briefing_service.generate_briefing(briefing_type)
    → Claude API: generate 90s script from live data
    → HeyGen API: POST /v2/video/generate
        avatar_id: d259c335741f4fc0b061e04c59388b4e
        voice_id: (HeyGen Sarah's voice — use default for avatar)
        script: generated text
    → Poll HeyGen status endpoint until complete (max 5 min)
    → Download video URL from HeyGen CDN
    → Store in DB: market_briefings table
    → Log result
```

## DATABASE

### market_briefings table
```sql
CREATE TABLE IF NOT EXISTS market_briefings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    briefing_type TEXT NOT NULL CHECK(briefing_type IN ('pre_market','open','close')),
    script_text TEXT NOT NULL,
    video_url TEXT,
    thumbnail_url TEXT,
    heygen_video_id TEXT,
    duration_seconds REAL,
    btc_price_at_generation REAL,
    status TEXT DEFAULT 'pending' CHECK(status IN ('pending','generating','completed','failed')),
    published BOOLEAN DEFAULT 0,
    generated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    published_at DATETIME
);
CREATE INDEX IF NOT EXISTS idx_briefings_type_date ON market_briefings(briefing_type, generated_at DESC);
CREATE INDEX IF NOT EXISTS idx_briefings_published ON market_briefings(published, generated_at DESC);
```
